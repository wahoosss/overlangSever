개인정보 처리방침

발효일: 2026 년 10 월 20 일 | 적용 대상: OverLang

본 앱은 화면의 텍스트를 실시간으로 번역하여 그 자리에 다시 그려 줍니다. 인식과 번역은 모두 사용자의 기기에서 이루어집니다. "무료 + 광고" 방식으로 운영되므로 광고를 불러오기 위해 인터넷에 연결하고, 사용자의 동의를 받아 필요한 이용 통계와 충돌 정보를 전송합니다. 본 앱은 Google Play 를 통해 배포되며, 개인정보 준수는 Google Play 정책과 EU 일반 개인정보 보호법(GDPR)을 따릅니다. 먼저 개요를 보여 드린 뒤 세부 사항을 설명합니다.

0. 30 초 요약

  • 사용자가 공유한 화면 내용은 기기에서 읽히고, 인식되고, 번역되고, 그려집니다. 그 과정에서 기기를 벗어나지 않으며, 처리된 프레임은 즉시 폐기되고 광고 타기팅의 근거로 쓰이지도 않습니다.
  • 번역 기록과 스크린샷은 기기 내 앱 전용 디렉터리에 저장됩니다. 다른 앱이나 웹사이트는 이를 읽을 수 없습니다. 한 건씩 또는 한꺼번에 삭제할 수 있으며, 앱을 제거하면 함께 사라집니다.
  • 본 앱은 Google AdMob 을 통한 광고 게재로 무료 운영을 유지합니다. 광고는 기기, 네트워크, 광고 식별자(GAID) 등의 정보를 사용합니다.
  • 최초 실행 시 동의하거나 거부할 수 있습니다: 동의 = 맞춤형 광고 + 통계 활성화; 거부 = 비맞춤형 광고만, 통계 비활성화. 어느 쪽을 선택하든 기기 내 번역 기능은 모두 정상적으로 작동합니다.
  • 우리는 사용자의 연락처, SMS, 통화 기록, 사진, 정확한 위치를 수집하지 않으며, 다른 앱에서 입력한 비밀번호나 결제 정보도 읽지 않습니다.
  • 광고와 통계에 필요한 정보 외에 유일한 네트워크 활동은 오프라인 모델 다운로드입니다: 번역 언어 팩(Google)과 OCR 문자 체계 모델(개발자 미러). 전송되는 것은 "특정 언어의 모델 파일" 요청뿐입니다.

1. 동의를 얻는 방법

최초 실행 시 앱은 가이드의 마지막 화면에 본 협약을 표시하고 기본으로 체크된 확인 상자를 제공합니다. 사용자의 동의는 기본 상태가 아니라 "사용 시작"을 능동적으로 누른 행위에 근거합니다:

  • 체크를 유지한 채 "사용 시작"을 누름 = 동의: 맞춤형 광고와 통계(Google Firebase Analytics)를 활성화합니다;
  • 체크를 해제한 뒤 "사용 시작"을 누름 = 거부: 통계가 비활성화되고 이용 데이터와 충돌 데이터가 수집되지 않습니다. 무료 운영을 유지하기 위해 광고는 계속 표시되지만 비맞춤형 광고로 전환됩니다;
  • 동의 또는 거부는 번역 기능 이용에 영향을 주지 않으며, 기기 내 모든 기능은 정상적으로 제공됩니다.

"비맞춤형 광고"에 관해: 광고를 요청하고 표시할 때 광고 SDK 는 여전히 기기·네트워크·광고 식별자 정보를 Google 에 전송하여 게재, 노출 빈도 제한, 어트리뷰션, 부정행위 방지에 사용합니다. 이 정보는 관심 프로필 구축이나 맞춤형 타기팅에 쓰이지 않습니다. "비맞춤형"은 광고가 타기팅되는 방식을 제한하는 것이지, 데이터 전송이 완전히 없어진다는 뜻이 아닙니다.

유럽 경제 지역(EEA) 및 영국 사용자: Google 이 제공하는 표준 동의 인터페이스(User Messaging Platform, UMP)를 추가로 보게 됩니다. 그곳에서의 선택은 위 체크박스보다 우선하며, 광고가 맞춤화되는지 통계가 활성화되는지를 직접 결정합니다. 그 선택은 언제든 철회하거나 변경할 수 있습니다: 앱의 "개인정보 처리방침 및 이용약관" 페이지 오른쪽 위에 UMP 개인정보 옵션 인터페이스를 다시 여는 입구를 두었습니다.

2. 어떤 정보를 왜 수집하는가

2.1 화면 내용: 기기에 머물고 사용 후 폐기

화면 녹화를 허용한 뒤: 프레임이 하나씩 읽힘 → 텍스트가 사용자 기기에서 인식됨 → 사용자 기기에서 번역됨 → 번역문이 오버레이의 원래 자리에 다시 그려짐 → 해당 프레임은 곧바로 폐기됨. 인식과 번역은 모두 사용자 기기에서 완료되며, 이미지·텍스트·번역문은 업로드되지 않습니다.

이 경로는 어떤 원격 서비스에도 의존하지 않습니다. 비행기 모드에서도(모델이 이미 다운로드되었고 광고를 표시하지 않는 경우) 인식과 번역은 완료됩니다.

2.2 번역 기록과 스크린샷: 앱 전용 디렉터리에 저장

  • 번역이 완료될 때마다 앱은 기기의 앱 전용 디렉터리에 원문·번역문·위치·시각을 기록하여 "번역 기록" 페이지에서 되돌아볼 수 있게 합니다. 다른 앱이나 웹사이트는 이 파일들을 읽을 수 없습니다;
  • "번역 기록" 페이지 설정에서 "원본 이미지 저장"을 켜면 해당 번역은 그 프레임의 스크린샷도 추가로 저장합니다. 이 역시 전용 디렉터리에만 존재하며 시스템 사진 갤러리에는 기록되지 않습니다;
  • 최대 기록 개수, 원본 이미지 저장 여부, 전체 기록 삭제는 모두 "번역 기록" 페이지 오른쪽 위의 설정에서 조정할 수 있습니다. 상한을 낮추면 가장 오래된 기록이 즉시 잘려 나가며 해당 스크린샷도 삭제됩니다;
  • 이 내용은 광고 및 통계 전송 경로에 들어가지 않으며(2.3, 2.4 참조), 앱을 제거하거나 앱 데이터를 지우면 함께 삭제됩니다.

유의: 화면 번역은 화면에 표시되는 모든 것을 읽으며, 여기에는 다른 사람이 사용자에게 보낸 메시지가 포함될 수 있습니다. 기록과 스크린샷은 이처럼 기기에 저장되므로, 기기를 안전하게 관리하고 공유하거나 백업하기 전에 그 내용을 확인하십시오.

2.3 광고 게재에 쓰이는 정보(맞춤형 동의 여부와 무관하게 발생)

광고를 불러오고 게재하며 중복 제거·어트리뷰션·부정행위 방지를 수행하기 위해, 광고 SDK(Google AdMob)는 다음 정보를 처리합니다:

  • 기기 및 앱 정보: 기기 모델, 브랜드, OS 버전, 화면 해상도와 픽셀 밀도, 앱 버전 번호, 언어와 지역;
  • 네트워크 정보: 네트워크 유형(Wi-Fi / 이동통신), IP 주소의 대략적인 소속 지역(전체 IP 는 저장하지 않음);
  • 광고 식별자: 광고 게재와 어트리뷰션에 쓰이는 기기 광고 식별자(GAID). 시스템 설정에서 재설정하거나 끌 수 있습니다.

동의하면 Google 은 위 정보를 맞춤형 타기팅에 사용할 수 있습니다. 거부하면 광고는 비맞춤형 방식으로 게재됩니다(제 1 부 참조). 광고 내용은 사용자의 화면, 인식 결과, 번역문, 기록을 읽지 않습니다.

2.4 통계와 충돌 진단에 쓰이는 정보(동의 후에만 수집)

제 1 부에 따라 동의 선택을 한 후에만(EEA/영국 사용자는 UMP 에서 통계에 동의한 경우), 앱은 Google Firebase Analytics 를 활성화하고 다음을 수집합니다:

  • 이용 정보: 기능 탭 횟수, 어떤 번역이 성공했는지 실패했는지의 결과 코드, 인식과 번역 각 단계의 소요 시간 범위 등을 이벤트로;
  • 진단 정보: 충돌 스택과 발생 위치. 안정성 문제 해결에 사용합니다.

전송되는 이용 정보는 "어떤 버튼을 눌렀는지", "이 번역이 성공했는지"와 같은 행동 값만 담고 있으며, 사용자가 공유한 화면 내용, 인식된 원문, 번역문, 기록 필드, 스크린샷, 텍스트 위치 좌표는 담지 않습니다. 거부하면 Firebase 가 초기화되지 않으며, 위 이용 데이터와 충돌 데이터는 한 바이트도 기기를 벗어나지 않습니다.

2.5 언어 모델을 얻기 위한 다운로드 요청

  • 번역 언어 팩: Google ML Kit 의 모델 다운로드 기능(Google Play 서비스 경유)이 선택한 목표 언어의 사전을 다운로드하며, 언어당 약 30 MB 입니다. 이 요청에는 기기 모델, OS 버전, 앱 패키지 이름, 요청한 언어와 모델 버전이 포함되고 사용자의 화면 내용, 인식 결과, 번역문, 신원 정보는 포함되지 않습니다; 처리와 보관은 Google 개인정보 처리방침에 설명되어 있습니다;
  • OCR 문자 체계 모델: 일부 언어의 인식 모델은 개발자가 호스팅하는 미러에서 HTTPS 로 가져옵니다. 요청은 "특정 문자 체계의 모델"만 담고 사용자의 이미지나 텍스트 데이터는 담지 않습니다.

2.6 수집하지 않는 것

  • 신원 정보: 이름, 전화번호, 이메일, 주소 — 요청하지도 수집하지도 않습니다(앱에는 계정 체계가 없고 가입이나 로그인이 필요 없습니다);
  • 민감 데이터: 연락처, SMS, 통화 기록, 사진, 정확한 또는 대략적인 위치 — 앱은 이 권한들을 요청하지 않으며 읽지도 않습니다; 다른 앱에서 입력한 비밀번호와 결제 정보는 앱이 인식·기록·업로드하지 않습니다;
  • 기기 식별자: 앱 자체는 IMEI, Android ID 등 프로파일링에 쓰이는 식별자를 요청하지 않습니다; 광고 식별자(GAID)는 광고 SDK 가 게재와 어트리뷰션에만 사용하며, 시스템 설정에서 재설정하거나 끌 수 있습니다;
  • 동의하지 않은 경우: 어떤 이용 통계나 충돌 로그도 기기를 벗어나지 않습니다.

3. 우리가 요청하는 권한과 그 이유, 그리고 하지 않을 일

  • 화면 녹화(MediaProjection): 사용자가 능동적으로 공유하기로 선택한 화면 내용을 읽어 텍스트를 인식합니다. 시작할 때마다 시스템 대화상자에서 확인해야 하며, 공유 세션 동안 시스템은 지속적인 "화면 공유 중" 표시를 보여 주고 그곳에서 언제든 중지할 수 있습니다;
  • 다른 앱 위에 표시(오버레이): 원문 위에 번역문을 제자리에 그리고 시작 / 중지 제어 버튼을 배치합니다;
  • 포그라운드 서비스: 다른 앱으로 전환해도 번역이 계속 실행되게 합니다. 이 기능은 자격 증명으로 지속 알림이 필요하지만, 앱은 알림 표시 권한을 요청하지 않습니다: Android 13 이상에서 앱의 알림 표시를 허용하지 않았다면 이 알림은 나타나지 않으며 번역에는 영향이 없습니다 — 이 경우 시스템의 "화면 공유 중" 표시와 화면 위의 플로팅 제어 버튼으로 실행 여부를 알 수 있고 중지할 수 있습니다;
  • 네트워크 접근과 네트워크 상태: 광고를 불러오고, 동의 후 이용 통계를 전송하고, 2.5 에서 설명한 언어 팩과 인식 모델을 다운로드하며, 다운로드 실패 시 "네트워크가 없거나 연결이 제한됨"을 알리는 데 사용합니다;
  • 앱은 카메라, 마이크, 연락처, 위치, SMS, 저장소, 사진 갤러리 쓰기 권한을 요청하지 않습니다.

권장 사항: 결제, 신분증 문서, 타인의 사생활이 관련된 페이지에서 화면 번역을 오랫동안 켜 두지 마십시오. 그러한 페이지에서 기록과 스크린샷을 남기면 기기에 저장됩니다. 정말로 번역이 필요한 화면에서만 이 기능을 사용하십시오.

4. 제 3 자 SDK 목록

앱에 통합된 모든 제 3 자 SDK 와 구성 요소를 아래에 나열하며, 각각 "누구인지, 어떤 정보를 수집하는지, 무엇에 쓰는지"를 한 줄로 설명합니다; 완전하고 최신인 처리는 각 공급자의 공식 개인정보 처리방침이 규정합니다(링크를 눌러 확인). 본 페이지에 나열되지 않은 제 3 자는 앱에서 실행되지 않으며, 목록 업데이트는 앱 버전에 함께 배포됩니다.
